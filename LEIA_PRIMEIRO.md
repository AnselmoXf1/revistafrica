# 📖 LEIA PRIMEIRO - Guia de Início Rápido

## 🎯 O que foi feito?

Seu site foi configurado para que os artigos apareçam nas buscas do Google.

**Antes:** Artigos não apareciam no Google ❌
**Depois:** Artigos aparecem no Google ✅

---

## ⏱️ Tempo Total

- **Deploy:** 5 minutos
- **Espera:** 48 horas
- **Total:** ~2 dias

---

## 🚀 5 Passos Simples

### Passo 1: Fazer Deploy (2 minutos)
```bash
cd REID-main
git add .
git commit -m "feat: SEO - migrar para URLs limpas"
git push origin main
```

### Passo 2: Testar URLs (1 minuto)
Acesse no navegador:
- `https://revistafrica.com/artigo/123` (substitua 123)

### Passo 3: Enviar Sitemap (1 minuto)
1. Google Search Console
2. Sitemaps
3. Enviar: `https://revistafrica.com/api/sitemap.xml`

### Passo 4: Solicitar Indexação (1 minuto)
1. Google Search Console
2. Inspeção de URL
3. Colar: `https://revistafrica.com/artigo/123`
4. Solicitar Indexação

### Passo 5: Aguardar (48 horas)
Depois pesquise no Google: `site:revistafrica.com`
